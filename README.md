# 🏠 Real Estate Sales & Performance Analysis

## 📊 Project Overview

This project focuses on analyzing real estate sales and business performance using **Power BI, Python, and SQL**.

The dashboard analyzes property revenue, expenses, profit, sold properties, country-wise performance, monthly revenue trends, quarterly expenses, and agent performance for the years **2025, 2026, and 2027**.

The main analysis and interactive visualization were developed in **Power BI**, while **Python with Matplotlib** was used to create additional analytical charts.

---

## 🎯 Project Objectives

* Analyze overall real estate business performance
* Track revenue, expenses, profit, and sold properties
* Compare revenue across different countries
* Analyze expenses by country
* Identify monthly revenue trends
* Perform Pareto analysis of country-wise revenue
* Analyze quarterly expenses using Python
* Compare agent performance
* Create an interactive business intelligence dashboard

---

# 🗂️ Dataset

The project contains three datasets/tables.

## 1. Calendar

**Records:** 1,095 rows

### Columns

* Date
* Month
* Month Name
* Quarter

The Calendar table is used for time-based analysis and filtering.

---

## 2. Property Details

**Records:** 84 rows

### Columns

* Client ID
* Expense
* Image
* Name of Country
* Price
* Sale Date
* Size of Home
* Status
* Type of BHK

This is the main dataset containing property and sales-related information.

---

## 3. Customer Details

**Records:** 10

### Columns

* Client ID
* Image
* Name

Customer information is associated with properties through the **Client ID**.

## 🌍 Country-wise Revenue

### Matrix

A Matrix visual was created to analyze:

**Name of Country → Revenue**

This allows revenue generated by different countries to be compared easily.

---

## 🗺️ Country-wise Expense

### Shape Map

A Shape Map was used to visualize:

**Name of Country → Sum of Expense**

This provides a geographic view of expense distribution across countries.

---

## 📅 Monthly Revenue Analysis

### Ribbon Chart

A Ribbon Chart was used to analyze:

**Revenue by Month Name**

This helps compare monthly revenue performance and observe changes in the ranking of months.

---

## 📊 Pareto Analysis

### Pareto Chart — Revenue by Country

A Pareto analysis was created using:

* Name of Country
* Revenue

The visualization combines a **bar chart** with cumulative analysis to identify countries contributing significantly to total revenue.

The Pareto chart was created using **Python and Matplotlib**.

---

## 🐍 Python Analysis

### Area Chart — Expense by Quarter

Python with **Matplotlib** was used to create an Area Chart showing:

**Sum of Expenses by Quarter**

This helps visualize quarterly expense patterns and compare expense levels across different quarters.

---

## 👨‍💼 Agent Performance

An **Agent Performance Table** was created in Power BI to provide a detailed view of agent-level performance.

The table helps compare agent performance based on the available sales-related metrics.
